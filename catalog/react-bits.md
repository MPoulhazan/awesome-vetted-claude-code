## Install

Recommended scope: Project dependency

```
npx shadcn@latest add @react-bits/SplitText-TS-TW
npx jsrepo@latest add https://reactbits.dev/r/SplitText-TS-TW
```

The suffix picks JS or TS, then CSS or Tailwind. Use on marketing pages, sparingly inside app UIs.
