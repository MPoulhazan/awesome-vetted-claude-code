## What problem it solves

The default status line shows little. ccstatusline puts model, branch, context use and cost under your prompt.

## Security

| Runs code | Hooks | Network | Background process |
|---|---|---|---|
| Yes | No | No network | No |

Runs as your status line command, so it executes constantly with your permissions. Pin a version rather than @latest in settings.

## Install

Recommended scope: User-wide (`~/.claude`)

```
npx ccstatusline@latest
```

The interactive setup writes the statusLine command into your Claude Code settings.
